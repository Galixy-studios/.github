# Galaxy Studios — Engineering Standards

Organization-wide guidelines and templates for websites, mobile backends, APIs, and game services.

## How to use

- Use a separate repository for each independently maintained product or service.
- Read [CONTRIBUTING.md](CONTRIBUTING.md) before starting work.
- Open an issue for bugs, enhancements, or planned changes.
- Use a pull request to review and merge code into protected branches.
- Never commit secrets, client data, infrastructure addresses, or production credentials.

These are defaults. A project may define more specific guidelines in its own repository. This public repository intentionally contains no private operational documentation.
