# Security Policy

Do not disclose vulnerabilities publicly before maintainers have had a reasonable chance to investigate.

For repositories that support it, use GitHub's **Report a vulnerability** / private vulnerability reporting feature. Otherwise, contact a repository maintainer through an established private communication channel.

Never open public issues containing credentials, tokens, personal data, internal IP addresses, or exploit details. Rotate and revoke any exposed credentials promptly.

Security fixes should be tested and reviewed before release. Each application should document any additional supported-version and reporting requirements in its own repository.
